# social-images

Pictures that go with posts on [@nixfred](https://x.com/nixfred). Everything in this repo is public on purpose.

Each file is named by the hash of its contents, so a link never changes and nothing here says where a picture came from. Pictures only: no text, no keys, no private files.

Added by Social HQ when a post with a picture is scheduled through ClimbX (ClimbX can only attach pictures it can fetch from a public link).
